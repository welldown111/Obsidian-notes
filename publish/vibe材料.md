## ai 编程工具

### codex
可以去sorryios，25元一个月，8人共享的，可自行根据需求购买
![[Pasted image 20260416154420.png]]
采用这种方式买了gpt plus的话，网页的可以直接用gpt5.4-thinking，挺好用的。也可以在自己电脑上装一个codex
![[Pasted image 20260416155446.png|218]]
直接点那个codex之后下载就行，下了可以在自己本地电脑上用

但买gpt plus不会给api的，是用oauth登录的。
![[Pasted image 20260416155638.png|272]]
额度还是比较耐用的。

或者淘宝咸鱼这些平台搜gpt plus，太便宜的可能没售后
貌似还有codex 30天随便用，但估计得一两百。

### claude code

我个人是在这个第三方平台买的：foxcode
https://foxcode.rjj.cc/
去官网买太贵，还非常容易封号。

去这里面可以买token，可以用claude code，codex和gemini也都可以，但是用claude的话价格比较贵，token耗的比较快。
![[Pasted image 20260416154904.png]]

买了之后按照教程配置，就可以正常使用api了。
里面还有一些别的教程，比方说配置openclaw什么的，但是写的很简略，（他写这个也是让你多用token），我个人不太推荐不太熟练的时候用openclaw，更推荐玩玩儿codex，他逐渐也具备openclaw的那些工程上的设计了。
